# TrustPulse

## The Financial Resume for the Credit-Invisible

TrustPulse is a borrower-first financial identity builder that turns legitimate everyday financial evidence into an explainable Financial Resume.

## MVP

The MVP contains four major stages:

1. Financial Identity
2. Evidence Vault
3. AI Evidence Analysis
4. Trust Profile + Recommendations + Financial Resume + Decision Card

The MVP ends at the Decision Card.

## Architecture

- Frontend: Next.js / React
- Backend: FastAPI / Python
- Database: PostgreSQL
- Storage: Cloud object storage
- AI: Cloud AI API
- Configuration: Environment variables

## Principles

- Cloud-first from the beginning
- AI interprets
- Deterministic rules score
- Evidence is validated and triangulated
- Trust and Confidence remain separate
- English and Hindi are MVP languages
- Borrower-only MVP
- No hardcoded secrets
- No permanent local file storage
- No SQLite
